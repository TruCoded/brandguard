# Demo script (about 5 minutes)

1. **Dashboard.** Island home: live counts, click Content Review.
2. **Review.** Paste the sample caption. Show evidence, reason, confidence, "safe to apply". Apply safe fixes. Apply the claim fix (human check recommended). Dismiss one finding with a reason.
3. **Image.** Upload a pink image: off-palette and missing alt text.
4. **Submit.** Routes to a reviewer. Switch to Maya: cannot approve. Switch to Leena: approves.
5. **Publishing.** Maya schedules, dry run passes. Mention an expired offer in a new draft: blocked.
6. **Customise.** As Admin add a custom rule (for example a medical-claim rule) and see it fire. Create a new brand in a new niche.
7. **Insights.** Rules dismissed often are flagged as probably unclear.
8. **Reel studio.** Baseline chart, best hook/CTA/length/time, plan a reel, send the caption to Review.
9. **Agent studio.** Run a topic; watch the log; it stops at a human approval.
10. **Audit.** Show the verified hash chain.
